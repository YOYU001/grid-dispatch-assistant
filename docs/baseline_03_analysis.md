## 解讀

- **格式不是問題**（JSON 100%），**規則才是問題**：flex 等級、ALL_FLEXIBLE、clear、期限換算、不動≠不需動作，這些是我們自訂的「公司規定」，短短的 system prompt 不足以讓模型學會 → 正是 SFT 要解決的事
- 安全面要特別盯：誤拒 9.4% 與漏拒 25%，訓練後兩者都要改善
- 真人題 core 45% 高於合成題，可能因為真人題多為單一要求、較少 ALL_FLEXIBLE／取消題；20 題誤差大（±20%），只作參考
